## Необходимые инструменты и запуск сайта

Чтобы использовать данное веб-приложение нужно установить ***transliterate*** и ***django***, чтобы это сделать  
напишите в терминале:

```shell
pip install transliterate
```

```shell
pip install transliterate
```
```shell
pip install pillow
```

А затем:

```shell
py manage.py runserver
```
